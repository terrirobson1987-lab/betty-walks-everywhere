BETTY WALKS - FREE INSTALLABLE WEB APP

Upload the contents of this folder to an HTTPS static web host such as GitHub Pages or Netlify. Open the hosted URL in Chrome on Android and select Add to Home screen / Install app.

GPS requires HTTPS and location permission. Keep the app open while tracking; Android may suspend tracking when the screen locks. Map tiles and route calculations need internet. Routes use a public demonstration routing server and may not be suitable for pedestrians: check all paths, crossings and access before walking. Walks are saved only in the browser on your device; clearing site data deletes them.
